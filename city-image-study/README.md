# Цифровой город — самостоятельный 3D-мир

Отдельная реконструкция по `city-original.png`. Встроенный WebGL-мир с пятью объёмными экспонатами, переключением общего вида и первого лица, автоматическими маршрутами и свободной ходьбой. Картинка служит только референсом: она не используется как геометрия или фон 3D-сцены.

## Запуск

Из этой папки:

```powershell
npm ci
npm run build
node serve.mjs
```

Открыть http://127.0.0.1:8766/city-image-study/index.html . Для просмотра уже собранного `dist/world.js` достаточно `node serve.mjs`. Сервер слушает только 127.0.0.1. Он раздаёт корень локального лендинга, чтобы работал прежний адрес.

В Windows можно запустить `start-city.cmd` двойным щелчком, затем открыть адрес выше. Нужен установленный Node.js. Установка зависимостей для просмотра готовой сборки не требуется. После распаковки архива сохраняйте имя папки `city-image-study`.

## Управление

- Общий вид: перетаскивание вращает камеру; колесо и ± меняют расстояние.
- Кнопки пяти экспонатов или клик по витрине запускают маршрут внутрь города.
- Внутри: WASD — ходьба, стрелки вверх и вниз — ходьба, влево и вправо — поворот взгляда, Shift — ускорение, зажатая мышь / перетаскивание пальцем — взгляд.
- Экранные стрелки позволяют идти вперёд и назад и поворачивать взгляд на любом устройстве.
- «Обзор мышью» запрашивает pointer lock только по явному клику; Esc освобождает курсор. При отказе браузера остаётся перетаскивание.
- «Весь город» ведёт к входу и возвращает общий вид. Новая витрина во время ходьбы перестраивает маршрут из текущей позиции. Во время воздушного спуска выбор ожидает безопасного приземления.
- «Без пролётов» переключает режим сразу. По умолчанию учитывается системный `prefers-reduced-motion`.
- «Графика»: высокая — тени и умеренный bloom; лёгкая — без постобработки и теней, меньшая плотность пикселей; авто снижает качество при устойчиво медленных кадрах.
- `?debug` показывает у входа проверочный манекен высотой 1,7 м.

## Пространство

Одна единица = один метр. Глаза находятся на 1,65 м над пешеходной поверхностью; вертикальный FOV внутри — 70°. Уровни: 0, 3,2, 7,2 и 11,2 м. Верхняя кровля — 18,2 м. Ступени — 17,4–17,8 см. Навигационный радиус посетителя — 28 см.

Общий вид и первое лицо используют одну PerspectiveCamera с явно разделёнными состояниями. Верхний вид адаптирует дистанцию под узкий экран; архитектура и все экспонаты остаются объёмными при любом ракурсе.

## Файлы

- `src/config.js` — общие размеры архитектуры, лестниц, площадок, препятствий и точек осмотра.
- `src/world.js` — процедурная архитектура, стекло, рамы, экспонаты, растения, подсветка, портал под переходом и световая лента.
- `src/navigation.js` — высота поверхностей, проверка тела посетителя, движение с дробными шагами, сетка A* и проверка каждого сокращаемого участка маршрута.
- `src/camera.js` — обзор, воздушный вход, пешеходные маршруты, ориентация, прибытие и возврат.
- `src/input.js` — клавиатура, мышь, pointer lock с fallback и экранные кнопки.
- `src/main.js` — рендерер, UI, постобработка, адаптация качества, resize и диагностика.
- `index.html`, `style.css` — адаптивная оболочка.
- `tests/navigation.test.js` — проверки маршрутов, ручной ходьбы, коллизий, масштаба и воздушного входа.
- `dist/world.js` — локальный production bundle; `.map` помогает отладке.
- `previous-image-viewer/` — неизменённая предыдущая 2.5D-версия для сравнения и отката.
- `city-original.png` — исходный референс, сохранён без изменений.
- `QA.md` — фактически выполненные проверки и ограничения.

## Технологии и лицензии

Three.js 0.187.0 (MIT) — WebGL 2, перспективная камера, PBR-материалы, геометрия, OrbitControls, CatmullRomCurve3, кватернионы и постобработка. esbuild 0.28.2 (MIT) используется только при сборке. Лицензии зависимостей сохранены в `THIRD_PARTY_LICENSES.txt`.

React и физический движок не нужны: размеры конечного архитектурного уровня известны, а навигация использует общие с рендером поверхности и препятствия. Сетка строится один раз; далее маршруты рассчитываются по запросу. Мелкая статичная геометрия объединена по материалам, растения инстансированы, теневая карта обновляется только при необходимости. В скрытой вкладке или вне экрана рендер приостанавливается.

Документация: https://threejs.org/docs/ и https://github.com/mrdoob/three.js . Платных API, облачной генерации, внешних моделей, сетевых шрифтов и внешних runtime-загрузок нет.

## Честные границы реконструкции

Это новая геометрия по мотивам одной картинки, а не точное восстановление исходной модели. Пять витрин, центральная башня, тёмный металл, фиолетовые акценты, растения и зелёная лента сохранены композиционно. Скрытые стороны и пешеходные соединения спроектированы самостоятельно; лестницы удлинены для человеческого шага.

Материалы и освещение браузерные, без path tracing. Отражения основаны на процедурном окружении, а не на полном отражении соседних зданий. На верхнем плане и в стекле результат отличается от исходного фотореалистичного рендера. Графическое сходство нельзя считать пиксельно точным.

Ходьба ограничена спроектированными поверхностями; прыжков, свободного полёта, выхода за границы основания и VR нет. На лестницах навигационная высота плавная, поверх видимых ступеней. Опорные конструкции, витрины, клумбы, ограждения и края участвуют в ограничениях движения; не применяется универсальная физика произвольных мешей.

28 ноября 2026 одобренная сцена подключена к главной странице лендинга как сохранённая версия 1 города (версия 11 сайта). Дальнейшие изменения движения и визуала планируются отдельно.
