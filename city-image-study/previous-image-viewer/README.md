# Цифровой город: интерактивный оригинал

Отдельный вариант для согласования. Главная страница не изменена.

Здесь используется точная копия изображения, прикреплённого пользователем. Никакая геометрия города не заменена. При выборе витрины происходит плавное изменение центра и масштаба изображения; доступны перетаскивание, колесо, щипок двумя пальцами, кнопки и клавиатура.

Это 2.5D-просмотрщик, а не полная трёхмерная реконструкция: новые ракурсы и скрытые поверхности из одного кадра не создаются. Приближение ограничено исходным разрешением 1536 × 1024. Интерфейс честно обозначает «Оригинальный рендер · интерактивное приближение».

Открывать index.html через любой статический сервер. Сборка и установка зависимостей не нужны. Для будущего встраивания можно использовать iframe с этим файлом. Пять точек фокусировки заданы в viewer.js в координатах исходного изображения.

Навык и библиотека рассмотрены как справочные материалы, не установлены. Контроллер движения написан для конкретных пяти витрин.
