# Страница «Работы»

Третья страница личного сайта: три проекта в соседних карточках на одном экране. Внутри каждой карточки — собственная анимированная сцена; бронирование в «Зерне» интерактивно.

- Reels Finder — поиск и разбор Reels;
- TACT — управление гибкими сменами и персоналом;
- «Зерно» — онлайн-бронирование столиков.

Страница не требует сборки: откройте `index.html` в браузере. Для разработки можно запустить любой локальный статический HTTP-сервер в корне проекта.

В демосцене Reels Finder использованы иллюстративные кадры из видео Pexels: [1](https://www.pexels.com/video/woman-talking-in-front-of-a-camera-8814086/), [2](https://www.pexels.com/video/a-man-recording-himself-talking-in-front-of-the-camera-6617461/), [3](https://www.pexels.com/video/women-talking-while-in-front-of-the-camera-6954275/). Это обложки для макета, а не результаты поиска сервиса.
